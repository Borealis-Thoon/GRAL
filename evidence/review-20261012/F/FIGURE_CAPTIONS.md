1. `precision_loss.png`: Contributions retained after repeated additions in the extracted production accumulation code, for 100, 1000 and 3000 constructed updates. The baseline loses all of the added amount in these stress cases. The candidate retains 96% in the 100-update small-increment case and 100% in the other plotted cases. Every candidate output matches the exact sum rounded once to float; the 96% result reflects final rounding. This isolates round-off and does not represent an atmospheric field.

2. `synthetic_output_difference.png`: Baseline-to-candidate concentration differences in the six original basic Main cases. These use 100, 1000 and 3000 particles in stationary and transient modes. The values describe stored output differences and do not measure error against a true atmospheric concentration.

3. `extended_output_difference.png`: Relative L1 concentration differences in six additional Main conditions. The tests prescribe 2.5 m/s wind with stability class 2 or 0.5 m/s wind with stability class 6, use 10 or 40 m grids over the same 200 m field, and allocate 100, 1000 or 3000 particles. Each condition has two repeats per model variant. The observed range is 0.0000152225% to 0.0018212145%. Several settings vary together. The figure describes the tested conditions and cannot isolate each setting's effect. These are output differences, not atmospheric accuracy estimates.

4. `memory_cost.png`: Numeric payload for the normal concentration buffers alongside measured managed array allocation. The existing float buffer uses `4E` bytes and the added double buffer uses `8E` bytes, for a combined `12E`, where `E = (NXL + 2) * (NYL + 2) * NS * SourceGroups.Count`. The six allocation measurements use one or nine slices and 2, 32 or 99 source groups. Array headers and references add to managed allocation. Total model memory was not measured.

5. `accumulation_lifecycle.png`: The normal horizontal concentration path with the candidate. Both particle loops add to the double buffer under a lock on the source-group leaf array. After tracking, completed sums move to the existing float buffer before volume correction and output. The transfer clears the double cells for the next weather situation.
