# GRAL GPU 결과 독립 검토

판정은 engineering_pass_observed_fixture다. 원시 출력·입력 해시·시드 상태·시간·메모리 대조 1,643개가 모두 통과했다. measured_v2의 그림 수정과 분석 수치 보존을 확인해 검토 범위의 발행 보류를 해제했다.

- 분석·검증 모듈을 불러오지 않고 22회 실행의 원시 GRZ를 struct와 NumPy로 해독했다. 50 × 50 고정 격자의 0을 유지했고 모든 값의 유한성·비음수성을 확인했다. 4~24시간의 NMAE, 편향, P95/P99, 공간 상관, 최대 차이와 R/V를 기존 분석과 대조했다.
- 세 source group과 aggregate의 12개 블록에서 R < 1을 만족했다. 최대 R은 0.0006840761이고 V 범위는 0.999881324~1.000057523이다. 전체가 0인 그룹과 CPU 대비값이 0인 블록은 이번 자료에 없었다. 해당 분기 검증은 별도 합성시험 근거가 필요하다.
- SG2의 정규화 편향은 여섯 시드에서 모두 음수였다. 절댓값은 1.96e-7~8.63e-7이며 블록 평균 절대편향/CPU 시드 간 절대편향은 최대 0.000203이다. 부호 경향을 기록하되 현재 크기에서 결함이나 원인을 단정하지 않는다.
- 모든 블록의 P95/P99 평균 절대차이는 해당 CPU 시드 간 차이보다 작았다. 가장 큰 비율은 SG3 P99의 0.05032였다. 이를 새로운 허용기준으로 사용하지 않았다. 시드와 그룹을 조합한 24개 최대농도 위치는 CPU/GPU에서 모두 같았다. 기본 시드의 공통 색상범위 지도와 부호 있는 차이 지도에서도 연기 분포의 누락과 주된 봉우리 이동은 관찰되지 않았다.
- 프로세스 시작부터 종료까지의 중앙값은 24시간 CPU 35.1781초, GPU 7.6466초이고 48시간 CPU 70.9471초, GPU 13.3384초다. 세 쌍별 속도비의 중앙값은 각각 4.6365배와 5.1650배다. CPU/GPU 시간 CV는 24시간 5.3790%/0.5716%, 48시간 4.8413%/1.9300%다. 단일 장비의 각 세 쌍 반복으로 한정한다.
- 동일 시드의 세 반복에서 CPU끼리, GPU끼리 해독 농도 배열이 완전히 같았다. 24시간과 48시간에 각각 성립하며 압축파일 바이트 동일성과 구분한다. 이 보충 비교는 실행 중 추가한 기술통계이고 독립 시드 수를 늘리지 않는다.
- 메모리 요약값을 원시 CSV의 관측 최대값과 대조했다. RSS·private bytes·OS peak working set을 구분해 기록하고 장치 전체 GPU 메모리를 프로세스 VRAM으로 해석하지 않는다. WDDM에서 프로세스 GPU 메모리는 확보하지 못했다. GPU 버퍼 계수는 애플리케이션 할당량이며 실제 VRAM 측정값과 다르다.
- GPU device event 누적값의 차분을 각 상황의 커널 시간과 대조했다. fresh_kernel_ms, residual_kernel_ms, kernel_total_ms는 호스트 실행·동기화·상태 읽기 시간이다. 이 값들은 roundtrip 안에 포함되므로 독립 단계처럼 더하지 않는다.
- 여섯 offset의 실제 시드 상태는 서로 다르고 각 CPU/GPU 쌍에서는 같다. 서로 겹치지 않는 세 사전 지정 블록만으로 난수열 독립성을 입증하지 못한다. measured_v2에서 그림 제목이 disjoint prespecified seed-pair blocks로 바뀌었고 Pearson r 축도 1-r로 표시됨을 확인했다.
- inference_inconclusive, formal_equivalence_not_tested, physical_validation_not_established를 함께 유지한다. 관측 공학 판정의 범위는 이 합성 사례와 저장된 결과다. 최종 통합 검토에서 기능행렬, offset=0 원본 비교, 동결 기록과 원본 스냅샷을 별도로 확인해야 한다.
