package_evidence.py의 증거 묶음 생성과 independent_scientific_review.py의 원자료 독립 재계산 코드를 검토했다. 지정된 두 파일의 정적 검토와 작은 합성 검사로 범위를 제한했다. 실행 중인 측정, 고정 입력, validation·analysis·모델 소스는 변경하지 않았다.

검토 중 세 가지 문제를 담당자에게 전달했고, 수정된 코드로 다시 확인했다. 패키저가 최종 support에 직접 쓰던 흐름을 support__staging에 복사한 뒤 rename하는 방식으로 바꿨다. 또 앞서 검증한 파일이 복사 전에 바뀌면 새 해시로 수용하던 문제를 고쳤다. freeze·review·artifact·snapshot의 기대 해시와 복사 직전 바이트를 대조한다. 독립검토가 공개 manifest의 상대 run.path를 현재 작업 폴더 기준으로 해석하던 문제를 manifest_path.parent 기준으로 수정했다. 절대 경로 처리와 실행 폴더 내부 검사는 유지한다.

작은 합성 검사 8개가 통과했다. 정상 내부 경로와 상위 폴더 탈출 거절, 기대 해시 변경 거절, staging 이후 승격, 두 값이 0인 비율과 분모 0 처리, 대칭 NMAE·bias·절대차, 표본 SD·CV, 공개 상대 경로 해석을 확인했다. 수정된 복사 루프와 경로 처리 구문은 실제 소스의 AST에서 추출해 검사했다.

수식은 고정된 격자와 출력 간격의 동일 가중치 조건에서 일관된다. L은 농도 차이의 절댓값 평균이며 농도 단위를 유지한다. 대칭 NMAE와 normalized_bias는 두 평균의 산술평균으로 나누므로 무차원이다. A·B·D는 같은 농도 단위이고 R=A/B와 V=D/B는 무차원이다. B가 양수일 때의 primary_pass는 A<B, B가 0일 때는 A=0과 일치한다. 분산 검토 범위는 0.5≤V≤2.0이다. 이 코드는 물리적 동등성을 자동 승인하지 않는다.

판정은 지정된 두 스크립트와 작은 합성 검사 범위의 승인이다. 남은 필수 수정 사항은 발견하지 못했다. 실제 측정 원자료, 최종 분석 결과, 전체 패키지 생성과 재현 실행은 이번 검토 범위에 포함하지 않았다. 승인 근거는 JSON에 기록한 두 파일의 정확한 SHA256에 한정한다.
