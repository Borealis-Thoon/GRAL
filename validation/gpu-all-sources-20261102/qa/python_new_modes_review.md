변경 내용: Python 서버가 정상상태·비정상상태 모드와 점·포털 배출원의 온도·속도 시계열을 받도록 확장됐다. 서버의 입력·출력 계약부터 합성 입력, 실행 통제, 새 측정 스크립트까지 차례로 검토했다.

필수 수정 사항은 발견하지 못했다. 검토 중 compare.py CLI에서 3SG 고정값을 확인했고 담당자가 입력 명세의 그룹 수를 쓰도록 수정했다. 합성 1시간·4SG 자료로 재검사한 결과 종료 코드 0, 출력 멤버 4개를 확인했다.

서버 독립 검사 7개와 validation 단위 검사 24개가 통과했다. 정상상태 모드의 Conz5d 생략과 residual 거절, 비정상상태 모드의 Conz5d 필수 조건, 허용 범위를 벗어난 모드 거절, 시계열 dtype·rank 오류의 조기 거절을 확인했다. 새 analysis 단위 검사 17개도 modeling-tools Python 3.12.14에서 통과했다. 기본 Python에는 Matplotlib이 없어 첫 분석 검사에서 환경 오류가 발생했으며, 지정 분석 환경으로 다시 실행했다. ruff·mypy·pylint·black은 설치돼 있지 않아 실행하지 못했다.

새 설계는 모드별 22개씩 총 44개 측정을 분리한다. 4SG 합성 입력은 면·선·점·포털 배출원을 각각 배정하며, 시간당 360000개 입자와 16개 작업자, 일정한 배출계수를 사용한다. 측정 실행기는 10초 유휴 조건을 5초 간격의 2개 표본으로 검사하고 CPU16..31의 상속된 affinity를 확인한다. 전후 파일 해시 검사, CPU/GPU 입력 일치, seed 일치, warm PTX cache 검사를 포함한다.

GPU 검사는 kernel_launches와 CUDA event 시간의 증가, 완료된 실행 요청의 입자 수, 정상상태 모드 residual 0, 비정상상태 모드 carryover를 확인한다. phase_counts는 성공한 GPU 요청 이후 서버가 갱신하는 host 누적값이다. 배출원별 장치 내부 입자 수는 계측하지 않는다. 배출원별 근거는 개별 합성 기능 검사, 고정된 4SG 입력, 양수 SG 출력, CPU 비교를 함께 해석해야 한다.

판정: 검토한 Python 코드와 비GPU 검사 범위에서 승인한다. 이 검토에서는 모델·GPU·시간 측정을 실행하지 않았다. 실제 장치 결과와 과학적 수치 판정은 별도 실행 근거로 확인해야 한다.
