# Evidence packaging plan

Run only after both 22-run cohorts and their independent analyses finish. Never run the packager during timing. The source PR and the separate evidence folder have different contents.

1. Import `study_input_files` and `sha` from `package_evidence.py`. For the frozen master manifest, make a JSON mapping `{portable_path: sha(source_path)}` before and after both analyses. Compare the complete mappings; save the equal mapping as `qa/analysis_inputs_manifest.json`. Preserve the two independent snapshots as review evidence.
2. Complete the independent review and bind `qa/final_review.json` to the master, freeze, results, snapshot, both cohort manifests, both summaries and both artifact manifests. The required keys are documented by the `bindings` dictionary in the script. `claims`, `scope`, and `limits` must be nonempty; `analysis_inputs_manifest_before_after_equal` and `formal_equivalence_not_tested` must be true. Report the actual statistical inference in `limits`, without assuming an outcome.
3. Run the packager with the verified Python after all source and review files exist. It writes to a new `publication/support__staging` and renames it to `publication/support` after the checks pass. A failed run may leave the staging directory; inspect and move it aside before retrying. Never treat staging as a finished bundle.
4. Independently check every file against `MANIFEST_SHA256.json`, review path rewrites and original manifests, and run portable analysis as a separate validation. These are not implied by packaging success. Publish the reviewed bundle separately under `validation/gpu-all-sources-20261102`; preserve pinned links to earlier evidence and legacy tests.

The public master and two public cohort manifests contain only portable run paths, relative protocol references, and master cohort links and hashes adjusted to the public manifests. Original manifests and raw logs remain byte-identical. The frozen source and overlay are verified in place; binary, build, cache, and repository metadata are excluded. Translator sources and new host tests belong in the evidence bundle, not the source PR. Case JSON provides functional evidence; functional run inputs and output are not included. Observer source is checked against the original observer hash in the overlay receipt.
